
# Proyecto Final – Sistemas Operativos II
## Infraestructura DevOps en Azure

### Descripción
Este proyecto implementa una arquitectura moderna basada en DevOps utilizando Microsoft Azure, Docker, Kubernetes y CI/CD.

### Tecnologías utilizadas
- Microsoft Azure
- Docker
- Kubernetes (AKS)
- Azure DevOps
- GitHub

### Estructura del proyecto
- app: código fuente
- docker: configuración de contenedores
- k8s: despliegue en Kubernetes
- pipeline: CI/CD
- docs: documentación
